# 盛夏黄昏海边便利店街角微缩场景（Seaside Konbini Diorama）架构与视觉设计规范

## 1. 目标与核心体验
构建一个可自由拖拽、旋转、缩放观察（第三人称环绕视角）的三维展示级微缩模型场景，呈现盛夏黄昏海边小镇街角便利店的治愈瞬间。
- **纯粹无 UI**：全屏画布渲染，画面内不出现任何按钮、标题、帧率面板、操作提示或水印。
- **完整正方形底座切片**：所有实体元素（便利店建筑、转角道路、停车位小货车、通海小巷、木阶梯、沙滩、半透明树脂切面浅海、防波堤、消波块、迷你灯塔及所有生活道具）严格收束在 `24 × 24`（X/Z 范围 `[-12, 12]`）的正方形展示地台内，绝不越界。
- **三渲二卡通渲染与微缩模型涂装感**：采用海盐蓝、奶油白、蜜桃橘、薄荷绿为主色调，清晰柔和的轮廓描边，结合哑光塑料涂装、半透明切割树脂海水、潮湿水洼晚霞/暖光倒影及高透落地玻璃。
- **无人物但充满生活余温**：不出现任何人物或人影，通过微歪的门口沙滩拖鞋、带水光的斜靠冲浪板、停靠的带藤篮自行车与浅蓝色小货车、偶发开合的自动门等细节，营造“刚刚有人离开”的安静叙事感。

## 2. 空间布局与坐标规划（正方形底座 `[-12, 12]`）
地台总尺寸为 `24 × 24`，底座底盘厚 `1.4`（`y = -1.4 .. 0.0`），形成整齐利落的树脂/木质展示托盘与地质剖面：
1. **便利店主体区（中心偏左后，`x: [-7.2, 2.2], z: [-7.8, -0.6], 地面标高 y = 0.55`）**
   - 正面朝向 `+z`（街角路口），右侧面向 `+x`（通海小巷与海滩方向开侧窗）。
   - 原创品牌 **「うみかぜマート」(Umikaze Mart)**，杜绝任何真实商标与乱码字符。
2. **L 形街角道路与停车位区（前侧与左侧，`x: [-11.8, 3.8], z: [-0.6, 11.8]` 及左侧道路 `x: [-11.8, -7.2], z: [-11.8, -0.6]`, `标高 y = 0.35`）**
   - 包含街角圆弧路缘石、混凝土排水沟与金属雨水篦子、白色反光斑马线、白色护栏、蓝色街角路牌与凸面转角镜、远处街角信号灯（约 `x = -10.2, z = 9.8`）。
   - 便利店左侧/前侧设白色标线停车位，停放一辆浅蓝色日式轻型小货车（Kei Truck）。
   - 柏油路面分布多处不规则浅水洼，实时映出蜜桃橘晚霞、路灯与便利店暖光。
3. **通海小巷过渡区（便利店右侧，`x: [2.2, 5.4], z: [-7.8, 2.5]`, `标高 y = 0.50 -> 0.25`）**
   - 侧墙挂载双层空调外机（配铜管与排水管，水珠滴入下方小水洼激起涟漪）。
   - 布置木质社区公告栏（张贴手绘风「夏祭り」「花火大会」「氷」海报，边角随风微掀）、分类垃圾桶、混凝土电线杆与交错垂弧电线、弯头暖光路灯及一株海边绿植小树。
4. **沙滩、半透明树脂浅海与远景防波堤区（右侧与右前/右后，`x: [3.8, 11.95], z: [-11.95, 11.95]`）**
   - 小巷尽头经通海小木阶梯落至干湿渐变的沙滩（`y = 0.25 -> -0.15`），点缀救生圈、收起的条纹沙滩伞、彩色贝壳与半透明海玻璃。
   - 右前至右侧边缘为浅海区域（水面 `y = -0.05`，海底沙床倾斜至 `y = -0.95`），外侧沿 `x = 11.95` 与 `z = 11.95` 形成晶莹半透明的海盐蓝树脂垂直切面，海岸线带涂装感白色泡沫浪花层。
   - 右后方（`x: [5.0, 11.6], z: [-11.6, -5.8]`）布置低矮混凝土防波堤、成簇四脚消波块（Tetrapods）与一座红白迷你灯塔。

## 3. 便利店室内外高细节清单
### 3.1 外观与门口道具
- 原创三色灯箱招牌（海盐蓝 `#4fa3c7`、奶油白 `#fff8ec`、蜜桃橘 `#ff9a76`、薄荷绿 `#68d3b8`）与街角独立灯箱立柱；
- 条纹布艺遮阳雨棚与屋檐日式玻璃风铃（附短册纸签）；
- 大面积高透落地玻璃橱窗与双扇自动感应玻璃门；
- 门口迎宾地垫与地垫边随意摆放的一双沙滩人字拖；
- 斜靠在店门窗边且带湿润水光的冲浪板、木质冲浪板架、撑开的条纹沙滩伞；
- 两台柔和发光的日式冷饮自动贩卖机、带棕色藤篮的薄荷绿复古自行车。

### 3.2 室内全景陈设（`3000K` 暖白偏暖黄照明）
- **靠前窗夏日限定陈列区**：彩色烟花礼盒、绿盘蚊香与小猪蚊香器、防晒霜展示架、沙滩小桶玩具、彩色透明游泳圈；
- **中区货架与鲜食**：整齐克制的零食/日用品双面货架、冷鲜阶梯柜（便当餐盒、海苔三角饭团、三明治）、杂志架、夏季冰淇淋玻璃卧柜、地面动线导视贴；
- **左/后区服务与设备**：收银台（收银机、暖光炸物保温柜、自助冰咖啡机、缓慢摇头旋转的薄荷绿小风扇）、靠侧窗冷饮吧台与高脚凳、整排带下沉白色冷雾的玻璃门饮料柜、储物柜、店内悬挂分类灯箱与海报、带圆窗的后场门。

## 4. 三渲二渲染与光影管线（方案 A）
- **色彩与天空**：自定义球形天空穹顶着色器，从海平线蜜桃橘（`#ff9e7d`）/珊瑚粉（`#ff7b89`）平滑过渡至海盐蓝（`#5b8fb9`）与天顶靛青（`#1f305e`），叠加慢速飘移的卡通晚霞云层。
- **冷暖光影对比**：室外采用微凉海盐蓝环境半球光 + 低角度暖橘晚霞平行主光（柔和阴影）；便利店室内布置多盏暖黄点光源，透过落地窗与自动门在店前路面洒下温暖光斑。
- **卡通着色与轮廓描边**：
  - 定制 4 阶柔和暖冷过渡梯度贴图驱动 `MeshToonMaterial`，辅以微弱哑光塑料边缘高光；
  - 关键建筑、底座、车辆、家具与道具统一挂载精确配比的反面法线外扩轮廓壳（深靛褐 `#23293d`）与结构硬边线稿，同时玻璃窗、半透明树脂水体、冷雾与光束标记 `noOutline` 独立渲染，确保透过玻璃看室内 100% 清晰通透；
  - 后处理管线配置抗锯齿与高阈值克制柔光（Selective Subtle Bloom），仅让灯箱、室内灯管与灯塔微微泛起温暖光晕，绝不过曝。

## 5. 11 项克制自然的循环动效
所有动效由纯函数时间状态机与统一 `AnimationSystem` 驱动，无缝循环：
1. 海浪轻推沙岸与白色泡沫生成消退；
2. 海风微拂（巷口树叶、屋檐风铃、遮阳棚前檐、公告栏海报掀角、交错电线微摆）；
3. 空调外机风扇微转 + 冷凝水珠下落 + 浅水洼同心涟漪扩散；
4. 自动门每隔约 16 秒缓慢滑开并闭合，同步微增门口地面暖光外溢强度；
5. 招牌灯箱与贩卖机局部灯带极轻微柔和闪烁；
6. 室内饮料柜与冷鲜柜白色冷雾粒子缓缓下沉循环；
7. 收银台旁小风扇叶片旋转与风头缓慢左右摆动；
8. 湿沙、浅水洼与潮湿斑马线上的晚霞/灯光倒影随微风轻轻晃动；
9. 远处街角交通信号灯慢速温和切换红/黄/绿光晕；
10. 远景迷你灯塔暖白光束缓慢扫过海面；
11. 暮色晚霞云层极慢速横移。

## 6. 模块化架构与 TDD 测试策略
采用 Vite + TypeScript + Three.js + Vitest 构建，按职责拆分为 `config`、`rendering`、`world`、`animation`、`app` 五层。每个模块均先编写失败的单元测试（覆盖边界包围盒不越界校验、材质与原创假名纹理校验、室内外全要素节点树完整性校验、11 项动效数学函数周期/幅度校验、HTML 零 UI 纯净度校验），通过后再实现并重构，最终经浏览器实机多视角截图与控制台零报错验证后交付。
