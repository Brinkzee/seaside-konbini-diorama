# 盛夏黄昏的海边便利店街角3D微缩场景 (`seaside-konbini-diorama`)

基于Three.js、TypeScript与Vite构建的日式青春动画风三维微缩景观。场景定格在盛夏傍晚的海边小镇街角，将原创便利店「うみかぜマート」、潮湿柏油路口、通海小巷、木阶梯、半透明树脂切面浅海与远景防波堤完整收纳在一块`24 × 24`的正方形展示底座内，支持全屏无UI的第三人称自由环绕观察。

## 场景概述与美术基调

- **三渲二卡通涂装质感**：以海盐蓝、奶油白、蜜桃橘与薄荷绿为主色调，搭配4阶暖冷过渡色带、柔和的深靛褐反面法线描边以及克制的高阈值柔光，兼顾动画背景的通透感与桌面微缩模型的实体涂装质感。
- **正方形树脂切面底座**：所有建筑、道路、车辆、植被、海岸与道具均严格收束在X/Z轴`[-12, 12]`的`24 × 24`正方形收藏级地台内，外侧形成干净利落的木质托盘边框与晶莹的海盐蓝半透明树脂海水切面。
- **原创假名视觉标识**：门头灯箱、街角立柱招牌、贩卖机面板、垃圾分类贴纸与夏日祭海报均由Canvas2D程序化绘制，采用原创店名「うみかぜマート」，不含任何现实商业商标或乱码字符。
- **无UI全屏画布与无人物叙事**：页面不挂载任何按钮、文字遮罩、帧率面板或水印。场景内不放置任何人物或人影，通过门口微歪的沙滩人字拖、带水光的斜靠冲浪板、停靠的藤篮单车与偶发滑开的自动门，保留“刚刚有人离开”的夏夜余温。
- **自由环绕相机交互**：默认以斜45度街角全景构图进入，支持鼠标左键拖拽旋转、右键平移焦点、滚轮无级缩放（最近可贴近玻璃橱窗查看货架细节，最远可俯瞰整座微缩底座）。

## 空间构图与室内外细节

### 1. 街角道路与店门外景
- L形转角潮湿柏油路面、白色反光斑马线、路缘混凝土排水沟与金属雨水篦子、白色护栏、街角路牌、凸面转角镜以及远处路口信号灯；
- 多处不规则浅水洼实时映出天边蜜桃橘晚霞、弯头路灯与便利店门头暖光；
- 左侧白线停车位内停放一辆浅蓝色日式轻型小货车；
- 店门外布置两台柔和发光的冷饮自动贩卖机、带棕色藤篮的薄荷绿复古自行车、斜靠窗边的水光冲浪板、木质冲浪板架、撑开的条纹沙滩伞、迎宾地垫、随意摆在地垫旁的一双沙滩拖鞋与三分类垃圾桶。

### 2. 通海小巷、沙滩与半透明树脂浅海
- 便利店右侧外墙挂载双层空调外机与冷凝排水管，下方衔接贴有「夏祭り」「花火大会」「つめたい氷」「なつ限定」海报的木质社区公告栏、混凝土电线杆、交错垂弧电线、暖光路灯与海边绿植小树；
- 小巷尽头经木阶梯自然过渡至干湿渐变的沙滩，散落救生圈、收起的条纹沙滩伞、彩色贝壳与半透明薄荷色海玻璃；
- 右侧及前后端面采用半透明海盐蓝树脂垂直切面呈现浅海剖面，可透视倾斜的海底沙床与岸边涂装感白色泡沫浪花，右后方延伸出低矮混凝土防波堤、成簇四脚消波块与红白相间的迷你灯塔。

### 3. 高透落地玻璃与15组暖光室内分区
正面与右侧采用低反射高透落地玻璃窗，室内以`3000K`暖黄灯光照亮全部15个功能分区，与室外微凉的海盐蓝暮色形成冷暖对比：
- **靠窗夏日限定陈列区**：手持与礼盒烟花、绿盘蚊香与小猪蚊香器、防晒霜展示架、沙滩小桶铲子套装、彩色半透明游泳圈与夏日三角彩旗；
- **中区与冷鲜陈设**：双排零食日用品中岛货架、阶梯式便当与海苔三角饭团冷鲜柜、整排带下沉冷雾的玻璃门饮料柜、夏季滑动玻璃盖冰淇淋卧柜、靠窗杂志架与地面导视贴；
- **收银与服务区**：收银台与暖光炸物保温柜、自助冰咖啡机、摇头旋转的薄荷绿复古桌面小风扇、靠前窗冷饮吧台与高脚凳、储物柜、室内悬挂分类灯箱海报及带圆窗的后场员工门。

## 11项自然循环动效

全部动效由纯函数时间状态机与`AnimationSystem`统一驱动，无缝循环且互不抢戏：
1. **海浪推岸与泡沫呼吸**：浅海水面轻柔起伏，岸边白色泡沫带随浪涌推进与消退；
2. **夏夜海风微拂**：巷口树冠叶片、屋檐玻璃风铃短册、条纹遮阳棚前檐、公告栏海报掀角与空中垂弧电线随风轻微摆动；
3. **空调冷凝水滴落**：侧墙空调外机风扇微转，排水管水珠周期下落并在下方小水洼激起扩散涟漪；
4. **自动感应门偶发开合**：双扇玻璃门每隔约16秒平滑滑开、停顿并闭合，同步增强门口路面的暖光外溢；
5. **灯箱与贩卖机微闪**：门头招牌灯箱及自动贩卖机灯带呈现极细微的柔和亮度起伏；
6. **冷柜白雾下沉**：室内饮料柜与冷鲜柜底部的半透明冷雾粒子缓慢下沉并循环再生；
7. **桌面小风扇摇头**：收银台角落的薄荷绿小风扇叶片持续旋转，风头左右缓慢摆动；
8. **潮湿路面与湿沙流光**：浅水洼、湿沙带与潮湿斑马线上的晚霞和灯光倒影随微风轻轻晃动；
9. **街角信号灯切换**：远处路口红绿灯按固定节奏温和切换绿、黄、红光晕；
10. **迷你灯塔扫海**：防波堤尽头迷你灯塔顶部的暖白光束缓慢旋转扫过海面；
11. **暮色晚霞云层漫移**：天空穹顶着色器中的卡通晚霞云层沿水平方向极慢速飘移。

## 技术架构与性能优化

- **静态几何与顶点色合批（`src/world/optimizeDioramaScene.ts`）**：在完整保留62个语义分组、11组动态节点独立层级以及玻璃/树脂透明排序的前提下，将静态纯色卡通网格烘焙为顶点色并连同静态反面描边壳按材质桶合并，使单帧累计Draw Call降低96.3%（稳定在`196`次左右，总三角形约`108,774`个），同时冻结静态矩阵更新与平行光静态阴影贴图。
- **GPU型号探测与自适应画质分级（`src/app/gpuAdapterProfile.ts`）**：启动时请求`powerPreference: 'high-performance'`，并通过`WEBGL_debug_renderer_info`识别当前上下文绑定的显卡型号，自动配置像素比、WebGL2多重采样抗锯齿与后处理柔光分辨率：
  - `discrete-ultra`（RTX / GTX / Radeon RX / Arc独显等）：最高`2.0`像素比、`4x` MSAA、`1.0x`柔光分辨率；
  - `integrated-balanced`（Intel Iris Xe / UHD / 核显等）：自动限幅`1.5`像素比、`2x` MSAA、`0.5x`柔光分辨率，减轻高分屏核显填充率开销；
  - `software-fallback`（SwiftShader等软件光栅化）：`1.0`像素比、关闭MSAA、`0.5x`柔光分辨率。
- **实时渲染遥测接口**：运行期在控制台输入`window.__dioramaStats`即可读取当前帧累计`drawCalls`、`triangles`、`geometries`以及`gpuVendor`、`gpuRenderer`、`gpuTier`、`pixelRatio`、`msaaSamples`、`bloomScale`等状态，不污染任何页面DOM。
- **离屏与后台自动休眠**：`#stage`启用`content-visibility: auto`，并结合`contentvisibilityautostatechange`、`IntersectionObserver`与`visibilitychange`事件，在页面隐藏或画布移出视口时自动暂停`requestAnimationFrame`渲染循环。

## 本地开发、测试与构建

环境要求：Node.js 18及以上版本。

```bash
# 安装依赖
npm install

# 启动本地开发服务器
npm run dev

# 运行Vitest单元测试套件（11个测试文件，51项测试）
npm test

# 执行TypeScript严格类型检查并构建生产产物
npm run build

# 预览生产构建产物
npm run preview
```

> **Windows双显卡设备开启独显小贴士**：部分Windows笔记本在节能或默认图形策略下会将Chrome / Edge的ANGLE后端绑定到集成显卡。若希望启用`discrete-ultra`满血档位（`2.0`像素比 + `4x` MSAA），可在浏览器设置中确认已开启「使用图形加速」，并在Windows「设置 -> 系统 -> 屏幕 -> 图形」中将`chrome.exe`或`msedge.exe`指定为「高性能」独立显卡，重启浏览器后查看`window.__dioramaStats.gpuTier`即可确认生效。
